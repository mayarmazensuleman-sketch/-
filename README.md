# مُقرر العقود المدنية — LAW2504

منصة تعليمية تفاعلية لمقرر العقود المدنية بجامعة أم القرى، كلية الدراسات القضائية والأنظمة.

- **إعداد:** الطالبة ميار مازن سليمان
- **إشراف:** د. منيرة عبدالعزيز العامر — أستاذ القانون الخاص المساعد
- **العام:** 2026م / 1448هـ

## المزايا

- خريطة تفاعلية لموضوعات العقود المدنية.
- شرح تدريجي للعقود: المفهوم، الأركان، الآثار، الأمثلة، والنصوص النظامية.
- بحث سريع في مواد نظام المعاملات المدنية من المادة 1 إلى المادة 721.
- شرح مركز البحوث بوزارة العدل مع رقم المجلد وصفحة ملف PDF.
- تحليل تعليمي للمادة وروابط للمواد المرتبطة.
- مختبر تفاعلي لمنهجية IRAC.
- تتبع تقدم الطالبة محليًا في المتصفح.

## المتطلبات

- Node.js 18 أو أحدث.
- npm.

```bash
npm install

```

```text
http://localhost:3000
```

## اختبار البناء الإنتاجي

```bash
npm install
npm run build
```

ينتج الأمر مجلد `dist/` الجاهز للنشر.

## النشر على Vercel

1. ارفعي هذا المشروع إلى GitHub.
2. من Vercel اختاري **Add New → Project**.
3. اختاري مستودع GitHub.
4. اتركي الإعدادات الافتراضية لمشروع Vite:
   - **Framework Preset:** Vite
   - **Build Command:** `npm run build`
   - **Output Directory:** `dist`
   - **Install Command:** `npm install`
5. اضغطي **Deploy**.

المشروع يستخدم مسارات أصول جذرية مثل `/assets/...` و`/data/...`، وهي موجودة داخل مجلد `public` وتُنسخ تلقائيًا إلى جذر الموقع أثناء البناء.

## ملاحظة حول الملفات التعليمية

ملفات PDF التعليمية مضمنة داخل `public/assets` وتُستخدم كمصادر قابلة للفتح من المنصة. جميع الملفات في حزمة التصدير أقل من 25 MB؛ أكبر ملف هو `judicial-precedents.pdf` وحجمه يقارب 22.56 MB.

## الترخيص والمصادر

المحتوى التعليمي وبيانات المقرر مخصصان للاستخدام الأكاديمي. تُنسب النصوص النظامية إلى مصدرها الرسمي، وتُذكر إحالات شرح مركز البحوث بوزارة العدل داخل المنصة.
